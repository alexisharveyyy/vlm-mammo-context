**EXPLORATORY: not part of the pre-specified analysis plan** (`docs/EXPLORATORY.md`, entry 1). No result here is a test of the
plan's hypotheses. Intervals are unadjusted 95% case-bootstrap percentile intervals
(2,000 resamples, seed 20261026).

Generated by `uv run python -m eval.surface_features` at commit `9353a80d498bdb284917d8aa843f6d7c4bb3baa7`. Input: tier T0 only,
Qwen3-VL, full images, `neutral`, forced format; 500 cases with a valid
answer. Case-level `p_malignant` averages the valid paraphrases. Per-case features
come from the local PNG masters and are not committed; this report holds
aggregates only.
